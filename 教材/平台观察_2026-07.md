# Agent 平台观察：2026 年 7 月

> 历史快照：已由 `教材/平台观察_2026-09.md` supersede，仅用于查看 2026-07 的变更背景。

> 校准日期：2026-07-30  
> 本文件记录高频变化的平台事实，不替代主教材中的稳定机制，也不作为永久型号或价格承诺。

## 本季度最值得进入课堂的变化

### OpenAI

- 2026-07-09 发布 GPT-5.6 系列。新增 Programmatic Tool Calling、显式 Prompt Caching、持久化 reasoning、`max` reasoning effort、Pro mode，以及 Responses API 的 Multi-agent beta。
- 2026-06-03 宣布弃用 Evals Platform、Agent Builder 和 reusable prompt objects。课程因此改为“本地 Eval harness 为主、平台为可替换后端”。
- 近期平台还提供 Background mode、Webhooks、Compaction、Hosted Shell、Skills、Computer Use 和 Tool search，适合用于讲解长任务 Agent 的运行时结构。
- 组织与项目层已有费用告警和 hard spend limit，成本控制应进入产品化验收，而不只是课后计算题。

- [OpenAI API Changelog](https://developers.openai.com/api/docs/changelog)
- [Model guidance / GPT-5.6](https://developers.openai.com/api/docs/guides/latest-model)
- [Responses API](https://developers.openai.com/api/docs/guides/migrate-to-responses)
- [Background mode](https://developers.openai.com/api/docs/guides/background)
- [Compaction](https://developers.openai.com/api/docs/guides/compaction)

### Anthropic

- 2026-06-30 发布 Claude Sonnet 5；2026-07-24 发布 Claude Opus 5。两者的默认思考方式、effort、tokenizer 和迁移行为与旧型号不同，不能只替换模型字符串。
- Claude Managed Agents 已覆盖 sandbox、session、memory store、subagent thread、webhook 和定时部署等能力。
- 支持在对话中动态变更工具，并尽量保持 Prompt Cache；这使“大工具面”设计从静态工具清单转向按阶段暴露工具。
- Workload Identity Federation、vault 和自托管 sandbox 值得进入安全章节，用来替代长期静态密钥和不受控执行环境。

官方资料：[Claude Platform Release Notes](https://platform.claude.com/docs/en/release-notes/overview)

### Google Gemini

- 2026-05-19 发布 Gemini 3.5 Flash GA，并推出 Gemini API 托管式 Agent 公开预览。
- 受管 Agent 可以在隔离的 Linux sandbox 中规划、执行代码、管理文件和浏览网页。
- 2026-06-24 为 Gemini 3.5 Flash 推出 Computer Use 公开预览，包含浏览器、移动端、桌面环境和提示注入检测。
- Google 当前建议通过 Interactions API 使用最新模型和能力，因此旧版单次 `generate_content` 示例不应承担完整 Agent runtime 教学。

官方资料：[Gemini API Changelog](https://ai.google.dev/gemini-api/docs/changelog)

### MCP

最新版 MCP Tools 规范已经覆盖结构化输出、补充输入、工具列表缓存、HTTP header 映射和显式状态 handle。课程需要从“会写 `inputSchema`”升级到“会设计多轮、可授权、可恢复的工具契约”。

尤其要纠正一个常见误解：MCP 2024-11-05 规范已经使用 `inputSchema`，它不是 2025 年从 `parameters` 改名而来的 breaking change。`parameters` 常见于模型厂商的 function calling 外层格式，两者属于不同接口层。

官方资料：

- [MCP 最新 Tools 规范](https://modelcontextprotocol.io/specification/latest/server/tools)
- [MCP 2024-11-05 Tools 规范](https://modelcontextprotocol.io/specification/2024-11-05/server/tools)

## 教学处理方式

这些更新不应变成一章“新品发布会”。课堂只抽取四个新的工程问题：

1. 长任务如何在后台运行、压缩上下文并恢复？
2. 工具很多时如何搜索、过滤、动态加载和维持缓存？
3. 执行代码、浏览网页和访问内网时如何隔离环境与凭据？
4. 平台功能下线时，Eval、状态和业务规则能否继续独立运行？

每次季度更新只需要替换本文件和主教材中的少量平台观察，不应重写 Agent 的基本闭环。
