# Agent 平台观察：2026 年 9 月

> 校准日期：2026-09-23  
> 本文件只记录需要进入课程判断的近期平台事实；模型名、价格、Preview 和 Beta 能力都不是永久承诺，使用前应再次核对官方文档。

## 本月应更新的工程判断

### OpenAI

- Agents API 已进入公开 Beta，提供托管式 Agent harness、session orchestration、上下文压缩和恢复；Responses API 与 Agents SDK 仍适合需要自行掌握状态、存储、审批和运行时的团队。
- GPT-5.6 系列支持 Programmatic Tool Calling、显式 Prompt Caching、持久化 reasoning、`max` reasoning effort 和 Multi-agent beta。Multi-agent 适合可并行拆分的研究、代码探索和审查，不应替代简单工作流。
- Prompt Cache Diagnostics 已 GA，课程应要求记录缓存写入、命中、未命中和端到端成本，而不是使用固定节省比例。
- Assistants API 已于 2026-08-26 关闭；新示例使用 Responses API、Conversations API 或 Agents SDK，不再把 Assistants 作为主路径。
- Background mode、Webhooks、Compaction、Tool search、Computer Use 和 Hosted Shell 共同说明：生产 Agent 的核心已从“循环调用模型”扩展到“可恢复任务运行时”。

### Anthropic

- Claude Opus 5.5 于 2026-09-22 发布，默认 1M context、128K 最大输出和 always-on adaptive thinking；`effort` 成为主要控制项，旧的 thinking 开关和部分 `tool_choice` 写法不能直接照搬。
- 9 月新增按需 Compaction、动态 inline tools 和 MCP connector 的 Beta 能力；工具表面可以在对话阶段按权限和任务动态变化。
- Computer Use 已脱离 Beta，Browser Use 以独立 toolset 提供浏览器语义控制。教学重点应放在沙箱、域名白名单、下载隔离、提示注入防护和高风险动作审批。
- Anthropic Python SDK 已进入 1.x，长期固定在 0.x 的示例应通过 adapter 隔离，并在迁移时重新验证参数和错误处理。

官方资料：[Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview)

### Google Gemini

- Gemini 3.8 Flash 于 2026-09-02 GA，定位长程软件工程、自主 Agent 和企业工作流。
- Gemini 3.8 Live 与 Extended Thinking 于 2026-09-15 GA，实时语音 Agent 可作为多模态选修案例。
- Gemini 3.7/3.6/3.5 Flash 已支持 agentic video understanding：按需读取转录、帧或音轨，适合讲“信息按需获取”而不是静态塞入长上下文。
- 2026-09-17 发布 Antigravity Agent 09-2026，旧的 05-2026 版本将于 10 月 5 日关闭；课程再次验证了“运行时与业务逻辑解耦”的必要性。

官方资料：[Gemini API release notes](https://ai.google.dev/gemini-api/docs/changelog)

### MCP 2026-07-28 规范（截至 9 月仍为 latest）

- Streamable HTTP 进入无协议级 session 的方向；跨调用状态应由服务端生成显式 handle 并作为普通工具参数传递。
- 增加 `server/discover`、`resultType`、`input_required` 和 Multi Round-Trip Requests；工具调用不一定一次返回最终结果。
- Tasks 移出核心协议，成为官方扩展；HTTP+SSE 和若干旧能力进入 Deprecated，不应在新项目中继续采用。
- `outputSchema`、`structuredContent`、工具列表缓存、`ttlMs`、`cacheScope` 和 OpenTelemetry trace context 应进入工具契约教学。

## 课程更新后的四个重点

1. 用 checkpoint、interrupt、resume、cancel 和幂等键讲可恢复执行。
2. 用 `input_required`、显式 handle 和 `outputSchema` 讲协议兼容，而不是只讲 schema。
3. 用并行 Subagent、wall-clock latency 和冲突仲裁讲多 Agent 的真实收益与代价。
4. 用 Computer/Browser Use 的沙箱与审批实验讲“行动能力越强，控制面越重要”。
